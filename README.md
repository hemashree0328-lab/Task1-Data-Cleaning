# Data Cleaning and Preprocessing

## 📌 Project Overview
This project demonstrates how to clean and preprocess the Customer Personality Analysis dataset using Python and Pandas.

## 🛠️ Tools Used
- Python
- Pandas
- NumPy
- VS Code

## 📂 Dataset
Customer Personality Analysis (Kaggle)

## ✨ Data Cleaning Steps
- Loaded the dataset
- Handled missing values
- Removed duplicate records
- Standardized column names
- Cleaned text data
- Converted date columns
- Removed outliers
- Saved the cleaned dataset
